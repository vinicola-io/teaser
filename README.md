# vinicola.io 티저

마스터 v4.4를 바탕으로 만든 정적 웹페이지입니다. 별도 빌드나 패키지 설치가 필요하지 않습니다.

- 로컬 실행: 프로젝트 루트에서 `python3 -m http.server 4173 --bind 127.0.0.1 --directory website/dist` 후 `http://127.0.0.1:4173` 열기
- 링크 연결: `dist/site.config.js`의 `researchUrl`과 `newsletterUrl`에 각각 공개용 Google Forms 응답 URL 입력
- 링크가 비어 있으면 접수 준비 중 안내가 표시됩니다. 실제 접수·구독 완료를 대신 표시하지 않습니다.
- 뉴스레터는 설문과 별도 폼입니다. 수집 안내와 수신 동의는 각 폼에서 설정합니다.
- 문의 이메일은 `contactEmail`에 입력합니다. 빈 값이면 문의 링크를 표시하지 않습니다.
- `.openai/hosting.json`은 검토용 비공개 Sites의 식별자입니다. 공개 범위 변경은 별도로 결정합니다.

페이지는 이메일·설문 응답을 저장하거나 방문 추적을 하지 않습니다. 와인 그래픽은 콘텐츠 예시이며, 대표 이미지는 AI로 만든 연출 이미지입니다.
